근데 캘빈 회로는 빛을 직접 안 쓰는데
왜 밤에는 멈추는 걸까?1
1캘빈 회로는 빛을 직접 쓰지 않지만, 명반응이 만든 ATP와 NADPH가 있어야 돌아가요. 밤에는 명반응이 멈춰 두 물질이 곧 바닥나므로 캘빈 회로도 함께 멈춥니다. 그래서 ‘암반응’보다 ‘탄소 고정 반응’이라는 이름이 더 정확해요.
그럼 밤에 식물은 에너지를 어디서 얻어?2
2낮에 만든 포도당을 녹말로 저장해 두었다가, 밤에 다시 분해해 세포 호흡으로 ATP를 얻어요. 세포 호흡은 빛과 상관없이 낮에도 밤에도 일어납니다.
