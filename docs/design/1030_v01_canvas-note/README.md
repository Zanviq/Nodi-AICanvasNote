## 1. 개요

태블릿과 펜으로 쓰는 손글씨 노트 앱 「AI Canvas Note」(가칭)의 첫 설계다. Nodi를 축소·개선해, 입력창 없이 필기 속 문장을 펜으로 두 번 톡 해서 묻고 답을 질문 바로 아래에 받는다. 이 묶음은 제품 범위, 두 번 톡 문장 고르기 알고리즘, 디자인 시스템, HTML 시안을 담는다.

크기가 큰 문서다. 아래 목차에서 필요한 절만 찾아 읽는다.
